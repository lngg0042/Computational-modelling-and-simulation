# Newton's Law of Cooling Simulation

## Overview

A Python-based simulation of Newton's Law of Cooling, developed as part of a Computational Modelling and Simulation project.

The project investigates how **ambient temperature** and **cooling rate** affect the temperature of an object over time. It also explores numerical accuracy using **Taylor series approximations** and analyses the impact of **floating-point errors** on the simulation.

## Objectives

* Model temperature changes using Newton's Law of Cooling.
* Investigate the effect of different ambient temperatures and cooling rates.
* Approximate the model using Taylor series expansions.
* Compare exact and approximated solutions.
* Analyse numerical and floating-point errors.

## Methods

* Exponential modelling
* Taylor series approximation
* Numerical error analysis
* Computational simulation
* Data visualisation

## Technologies

* Python
* NumPy
* Matplotlib

## Results

The simulation demonstrates how changes in ambient temperature and cooling rate influence the cooling behaviour of the system. Taylor series approximations were compared with the analytical solution to evaluate accuracy and numerical error.
